# 1520 kHz

Согласно актуальному летнему расписанию вещания на 2024 год (сезон A24), на этой частоте можно поймать следующие станции:

|Станция|Время вещания (МСК)|Примечания|
|---|---|---|
|**Международное радио Китая (CRI)**|03:00 - 05:00 (ночи)|Указана в расписании как одна из рабочих частот[](https://voiceoffreerussia.org/korotkie-volny-na-russkom-yazyke-sezon-a24-leto-2024/).|
|**Радио Японии (NHK)**|06:30 - 06:50 (утра)|В направлении на Дальний Восток России[](https://voiceoffreerussia.org/korotkie-volny-na-russkom-yazyke-sezon-a24-leto-2024/).|
